ABOUT THIS PROJECT

Built to explore.

ConceptLab 10 is a modular learning website for Class 10 Mathematics and Science. Its catalogue is intentionally empty until working experiment modules are added.

No filler. Only working labs.

The website shell provides navigation, subject workspaces, module discovery, and a responsive experiment stage. It does not invent chapter cards or ship placeholder experiments. A lab appears only when a valid JavaScript module exists in the relevant folder.

  • One independent JavaScript file per experiment.
  • Experiment metadata generates its title, category, description and selector.
  • Each lab runs inside an isolated Shadow DOM so its styles do not break the main website or other labs.
  • Switching labs aborts listeners and calls the module's cleanup function.
  • Responsive layout and reduced-motion support are built into the shell.

How modules are published

Add a finished .js file to the appropriate folder and push the change to the configured GitHub branch. GitHub Actions scans the folders and generates the manifest during deployment.

  • experiments/maths/ for Mathematics.
  • experiments/science/ for Science.
  • GitHub Pages hosts the resulting static website.
  • No Python launcher, backend, package installation or local server is needed for published visitors.
